User guide

New here? This page explains agentctx in plain language — then shows you exactly where to click.

1. What is this?

AI coding tools read files like AGENTS.md or CLAUDE.md for project tips. If those files are wrong or bloated, the agent wastes time and tokens. agentctx checks those files (and MCP server configs) for common mistakes.

2. What should I paste?

Paste markdown instructions (headings + bullet lists + real commands), not random chat text. For MCP, paste JSON that starts with {"mcpServers": ...}. If you type gibberish, the site will explain what went wrong instead of failing silently.

3. Recommended path for beginners

  1. Examples → open demo-bad → Scan context (see real errors)
  2. Same page → demo-good → Scan context (see a clean file)
  3. Studio → Fill clean sample → edit it → Generate report
  4. MCP Lab → Load bad sample → Validate (see secret/localhost warnings)
  5. Rules → skim what each message means
  • I ran demo-bad
  • I ran demo-good
  • I tried Studio with my own text

4. Reading the results

error must fix · warn should improve · info optional tip.

Common fixes: delete directory trees, update dead npm run … scripts, remove hardcoded API keys from MCP env.

5. Try random text safely

Go to Studio, type anything like asdfgh or a sentence of nonsense, then press Generate report. You’ll get a plain-English explanation and a starter template — not a cryptic crash.

MCP

Model Context Protocol — JSON configs that start tools/servers for the agent.

Gate

Runs context check + MCP check together (handy for CI).
