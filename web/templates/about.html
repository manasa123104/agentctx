About agentctx

A linter for AI agent context files and MCP configs — CLI first, with FastAPI and Django web desks.

What it catches

Missing paths, dead npm/make commands, directory-tree bloat, inferable stack prose, hardcoded MCP secrets, localhost URLs, and more.

How to run locally

node bin/agentctx.js check
node bin/agentctx.js mcp
node bin/agentctx.js gate

Web desks

FastAPI on port 8000 and Django on 8001 share this multi-page UI: desk, rules, examples, MCP lab, and studio.
